# Photo-reference menu icons

These eight transparent PNGs were generated with the built-in imagegen tool from
user-provided iPod nano Music and Playlists screenshots. They are recreations,
not extracted Apple asset files. The original layout was checked against
[Apple's iPod nano guide](https://support.apple.com/en-gb/docs/ipod/133772) and
[2012 photographs of the device](https://news.livedoor.com/article/detail/7097816/).

`genius.png`, `playlist.png`, `artists.png`, `albums.png`, `songs.png`, and
`genres.png` are Music menu icons. `smart-playlist.png` supplies the smart
playlist gear; `speaker.png` appears beside Now Playing. Slint embeds them and
renders them at menu size, preserving generated transparency.

The complete final prompts and original generated file paths are recorded in
[prompts.json](prompts.json). Each icon used a separate built-in generation call.
The project uses the copies in this directory.
