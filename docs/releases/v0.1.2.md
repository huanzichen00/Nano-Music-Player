Desktop update with Practice Mode, Landscape Lyrics, listening statistics, podcasts and more reliable background tasks.

### Highlights

- Practice from saved song markers with a preparation countdown and optional lead-in. Press **P** to open Practice Mode and **Space** to start, pause or cancel a countdown.
- Press **Q** for Landscape Lyrics, with artwork, song information and synchronized lyrics in a wide window.
- Explore listening statistics and history, with artist portraits and detail browsing.
- Subscribe to RSS podcasts and play episodes in the desktop player. Preview and merge music, playlists, lyrics and listening data through **File → Sync to iPhone…**.
- On macOS, optionally use the current song artwork as the desktop wallpaper, view battery and Bluetooth output information, and focus/hide the player with **Option + R / Option + Shift + R**.
- Use refreshed rounded desktop dialogs, improved elastic scrolling and complete album navigation, including shuffle from album song lists.
- Preserve playlist drafts, custom covers and newer lyric choices while background imports, translations and Genius playlist saves finish. Library refresh avoids rewriting unchanged cached tracks.

### Downloads

- **macOS Apple Silicon:** `Nano-Music-Player-0.1.2-macos-arm64.zip`. Extract and move **Nano Music Player.app** to Applications. The app is ad-hoc signed and is not notarized; macOS may require approval in System Settings → Privacy & Security.
- **Windows x86-64:** `Nano-Music-Player-0.1.2-windows-x86_64.zip`. Extract the complete folder and run `nano-music-player.exe`. This is an unsigned portable application.
- **Linux x86-64:** `Nano-Music-Player-0.1.2-linux-x86_64.tar.gz`. Extract and run `./nano-music-player`. Built on Ubuntu 22.04; requires compatible system audio, OpenGL and windowing libraries. On Ubuntu 22.04, install `libasound2 libudev1 libxkbcommon0 libxkbcommon-x11-0 libwayland-client0 libegl1 libgl1` if needed.

`SHA256SUMS` contains checksums for all downloads. Packages include third-party license notices and these release notes. GitHub also provides source archives for this tag.

### Notes

- This release distributes desktop applications. iPhone development sources are included in the repository; an iOS app is not included in these downloads. USB transfer requires the documented iPhone tooling.
- macOS wallpaper, device information and global shortcuts depend on native macOS integration. Wallpaper changes apply to the current desktop of connected displays; see the README for restoration and multiple-Space limits.
- Video playback requires an external libmpv runtime; video import and thumbnails require FFmpeg/ffprobe. These runtimes are not bundled.
- DeepSeek features require your own API key. Automatic folder monitoring remains disabled; manual import and finite library refresh are available.
- Physical audio output, native gestures and desktop integration still require manual testing on each target platform. Automated build success does not certify those interactions.
