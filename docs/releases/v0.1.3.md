Fixes the Windows window growing repeatedly while idle or after resizing.

### Windows fix

- Use a menu bar inside the application window. The native Windows menu height conflicted with frameless client sizing and caused repeated aspect/zoom corrections.
- Keep the window size stable when switching between Device Mode, Screen Mode and Landscape Lyrics. Window resizing and saved zoom remain available.
- Gate Windows packaging on real-window tests at 100%, 125%, 150% and 200% Slint scale factors, covering idle startup, mode changes, external resizing and saved zoom.

### Downloads

- **Windows x86-64:** `Nano-Music-Player-0.1.3-windows-x86_64.zip`. Extract the complete folder and run `nano-music-player.exe`. This is an unsigned portable application. If the previous version saved an enlarged window, choose **Settings → Appearance → Window Size** to reset it to your preferred size.
- **macOS Apple Silicon:** `Nano-Music-Player-0.1.3-macos-arm64.zip`. Extract and move **Nano Music Player.app** to Applications. The app is ad-hoc signed and is not notarized. macOS retains its native system menu bar.
- **Linux x86-64:** `Nano-Music-Player-0.1.3-linux-x86_64.tar.gz`. Extract and run `./nano-music-player`. Built on Ubuntu 22.04; compatible audio, OpenGL and windowing libraries are required.

`SHA256SUMS` contains checksums for all downloads. Packages include third-party license notices. Features and runtime requirements from [v0.1.2](https://github.com/huanzichen00/Nano-Music-Player/releases/tag/v0.1.2) remain applicable, including external libmpv/FFmpeg for video and the documented tooling for USB iPhone transfer.

Native window tests use the software renderer on GitHub's Windows runner. Physical multi-monitor DPI transitions, audio output and graphics-driver behavior still require device testing.
