An iPod nano inspired desktop music player, with local music playback, keyboard navigation, synchronized lyrics and a redesigned Settings interface.

### Highlights

- Play MP3, M4A, FLAC and WAV files, with shuffle, repeat, gapless playback and ReplayGain volume leveling.
- Browse artists, albums, genres and playlists; create and edit playlists and rate songs.
- Display local TXT/LRC lyrics, find lyrics online, and optionally generate translation and Japanese readings with DeepSeek.
- Use clearer Settings groups, visible switches and explicit choices for window style, size and volume preferences.
- Browse with keyboard, pointer or trackpad, with elastic scrolling and page transitions.
- Choose English, Simplified Chinese or Japanese, plus bundled font options.

### Downloads

- **macOS Apple Silicon:** `Nano-Music-Player-0.1.1-macos-arm64.zip`. Extract and move **Nano Music Player.app** to Applications. The app is ad-hoc signed and is not notarized; macOS may require approval in System Settings → Privacy & Security.
- **Windows x86-64:** `Nano-Music-Player-0.1.1-windows-x86_64.zip`. Extract the complete folder and run `nano-music-player.exe`. This is an unsigned portable application.
- **Linux x86-64:** `Nano-Music-Player-0.1.1-linux-x86_64.tar.gz`. Extract and run `./nano-music-player`. Built on Ubuntu 22.04; requires compatible system audio, OpenGL and windowing libraries. On Ubuntu 22.04, install `libasound2 libudev1 libxkbcommon0 libxkbcommon-x11-0 libwayland-client0 libegl1 libgl1` if needed.

`SHA256SUMS` contains checksums for all downloads. Each package includes third-party license notices. GitHub also provides source archives for this tag.

### Notes

- Linux and Windows packages are built on native GitHub runners. Physical audio output, desktop integration and gestures on those platforms still need user testing.
- Video playback requires an external libmpv runtime; video import and thumbnails require FFmpeg/ffprobe. These runtimes are not bundled. See the repository's video documentation for setup.
- DeepSeek features require your own API key. Network requests begin only after an explicit action.
- Automatic folder monitoring remains suspended in this playback recovery build. Manual import and startup refresh remain available.
