# Nano Music Player

[English](README.md) | 简体中文

一款使用 Rust 和 Slint 开发、灵感来自第七代 iPod nano 的桌面音乐播放器。设备模式显示完整机身、窄边框和 Home 按钮；屏幕模式仅显示屏幕区域。音乐播放、曲库浏览、键盘导航和同步歌词由统一的操作分发机制协调。

iOS 开发版复用桌面 iPod 界面与 Rust 服务，已完成签名安装和真机基础播放验证，生命周期验收见 [UI 检查记录](docs/IOS_UI_QA.md)。参见 [iOS 开发方案](docs/IOS_DEVELOPMENT_PLAN.md)、[构建与预览](ios/README.md)和[电脑传歌工具](docs/COMPUTER_TRANSFER.md)。

电脑端的 **文件 → Sync to iPhone…** 打开 USB 设备同步窗口，可先预览，再将音乐、歌单、歌词和播放资料合并到手机，保留手机独立资料及已有编辑。详见 [iPhone 同步说明](docs/IPHONE_SYNC.md)。

有关已合并分支、合并兼容性调整及验证结果，请参阅 [0.1.1 集成记录](docs/RELEASE_0_1_1.md)。

## 从源码运行

需要 Rust 1.92 或更新版本，以及可用的系统音频输出。

```sh
cargo run
# 使用独立的曲库和配置目录：
cargo run -- --config-dir ./local-config
```

macOS 上运行 `scripts/package-macos.sh` 会生成 `target/Nano Music Player.app`。添加 `--debug` 可构建较快的开发版本。界面图片已嵌入可执行文件。发布流程会为应用添加临时签名；尚未配置 Developer ID 签名和公证。

通过 **文件 → 导入音乐文件夹** 或 **Cmd/Ctrl + O** 递归导入文件夹。导入只读取音乐，并将元数据缓存到 SQLite，不会改写音频文件。音频保留在原位置；SQLite 保存路径、元数据、封面和歌词。程序没有人为设置曲库数量上限，实际容量取决于磁盘空间和内存。支持 MP3、M4A、FLAC 和 WAV；M4A 使用 Symphonia 的 AAC/ALAC 解码器，AAC M4A 已有真实音频样本测试。不支持或损坏的文件会被跳过，并显示提示。

macOS 的“文件”“播放”“视图”和“帮助”菜单位于系统菜单栏，由 Slint 的 Winit/Muda 集成提供。软件渲染测试截图中，这些菜单会以窗口内菜单的形式显示。

**Home**（机身圆形按钮，或非文本输入状态下的 Shift + H）可以穿过应用内对话框返回主页。在 Genius 预览中，**H / 左方向键 / Escape** 关闭预览，**L / 右方向键 / Enter** 创建或重试播放列表，并在结果就绪后播放；自定义导航按键在这里同样生效。Home 会隐藏尚未完成的播放列表草稿，再次选择**新建播放列表**可继续编辑。已经开始的保存操作会在后台完成。

搜索框获得焦点时，应用快捷键会暂停，以保留正常的文本编辑行为。按 Enter 或 Escape 将焦点交还搜索结果。切换页面或后台扫描时仍可控制播放。**帮助 → 键盘快捷键** 会按上表的三个类别显示当前实际使用的按键绑定。

有可用歌词时，封面上默认显示半透明、左对齐的歌词面板。点击封面或歌词，可同时显示 / 隐藏歌词面板、进度条、循环、随机播放和专辑曲目列表控件。封面会完整适配可用区域，不裁剪横图或竖图。播放控制和音量始终保留在底部。列表和歌词支持鼠标滚轮、触控板和指针拖动，边缘具有[橡皮筋阻力与回弹效果](docs/OVERSCROLL.md)。横向滚动可切换主页；页面圆点区域也支持鼠标拖动。拖动机身边框可移动窗口，拖动窗口边缘或使用缩放快捷键可调整大小，并保持显示比例。设备模式使用带圆角的透明外轮廓。**设置 → 外观 → 窗口置顶**默认开启，选择会被保存，也可从原生“视图”菜单切换。macOS 的三指拖移由系统触控板设置控制。

## 播客（桌面端）

打开首页 **播客 → 添加订阅…**，粘贴节目的 RSS 链接，预览后订阅。节目名称、封面、简介和单集列表自动获取；音频按需下载。公开 RSS 通常不需要账号或 API Key。

节目页支持手动刷新和取消订阅；点击单集播放，右侧信息按钮打开下载、删除、已听标记和简介。下载完成后使用现有音频引擎播放，支持断点续听。界面参考手册第 20–21 页：未听蓝点、按时间排序、自然播放结束后继续下一集未听或未听完的单集。播放页与歌曲页共用布局，点按封面显示进度、循环、回退 30 秒、速度和单集列表。取消订阅会保留已下载单集和收听记录。

此功能仅接入桌面端，使用独立的播客数据库和缓存，不进入音乐曲库或 iPhone 同步。首版不包含节目搜索和边下边播；0.5× / 1× / 2× 使用基础调速，音调随速度变化。操作及验证范围见[播客实现说明](docs/PODCAST_IMPLEMENTATION.md)。

## 歌词

在“正在播放”中，在封面、歌词或歌曲信息区域向右滑动或横向滚动，可返回之前的列表。左上角的**返回**按钮以及 H/Escape 具有相同作用，音乐会继续播放。纵向手势用于滚动歌词，拖动进度条和音量条仍按原有方式工作。按钮、图标和滑块使用普通箭头光标。可选的 AeroSpace 工作区跟随脚本见 [macOS 集成说明](docs/MACOS_INTEGRATION.md)。

通过 **文件 → 导入 / 替换歌词**，或 **设置 → 歌词 → 查找或编辑歌词 → 选择歌曲 → 歌曲歌词**，为歌曲关联 `.txt` 或 `.lrc` 文件。文件菜单操作优先作用于列表中选中的歌曲；不在歌曲列表时，则作用于当前播放的歌曲。手动导入的歌词优先级最高，重启、重新扫描或移动原歌词文件后仍会保留其内容。**移除歌词**会同时停止自动使用该歌曲的歌词；**使用自动歌词**会清除这一选择，并重新从音频标签及附近的歌词文件中查找，不会联网搜索。

自动发现会先查找音频旁边的同名 `.lrc`，其次为 `.txt`，最后读取音频内嵌的同步歌词或普通歌词标签。扩展名不区分大小写，空白歌词文件会继续回退到下一个来源。TXT 保持原始文本，支持滚动阅读。

LRC 支持同一行的多个时间戳、小数秒、正负偏移，以及 UTF-8、UTF-16 和 GBK 编码的外部歌词文件。当前行会跟随音频引擎的播放位置高亮，并滚动到可见区域；跳转进度也会同步更新高亮。增强型 LRC 的逐字标签会被转换为普通文本，当前只按行高亮。歌曲缺少歌词或封面时仍可正常播放，并显示对应的占位内容。不支持的 SYLT 时间单位会回退为普通歌词。

在 **设置 → AI 服务** 中输入 API 密钥和模型名称，默认模型为 `deepseek-flash`，密钥输入会被遮挡。也可在启动前设置 `DEEPSEEK_API_KEY` 环境变量；环境变量优先，且不会被写入凭据文件。打开对话框时密钥框保持为空，保存空值会保留已保存的密钥。凭据单独保存在配置目录下的 `deepseek.json`，macOS/Linux 上仅允许文件所有者访问。这是本地明文文件；它及其临时文件均已排除在 Git 版本控制之外。

对已有日语歌词的歌曲，打开 **歌曲歌词 → 生成罗马音**。此操作会将歌曲标题、艺人及现有日语歌词行发送给 [DeepSeek API](https://api-docs.deepseek.com/api/create-chat-completion/)，使用量计入你的 DeepSeek 账户。生成在后台进行，将较小字号的罗马音加在原文下方，不改动歌词正文或 LRC 时间戳。重复歌词行复用同一读音，非日语行保持不变。罗马音保存在 SQLite 中，生成后可离线使用；原歌词文本或时间戳发生变化时，旧注音会隐藏，直至重新生成。

单独按 **R** 仅在歌曲界面（包括选中音量条时）显示 / 隐藏罗马音；**设置 → 歌词 → 日语罗马音**会保存这一显示偏好。已有的自定义 R 绑定优先。**取消罗马音生成**会丢弃待应用的结果，并阻止后续批次；已经发出的 HTTP 请求可能继续运行，最长受其 120 秒超时限制。**移除罗马音**只删除注音，保留原歌词。不完整或无效的结果不会覆盖已有注音。汉字读音可能有歧义，生成结果需要自行核对；原文和时间戳始终保留。

打开 **音乐 → Genius 混音**，或“正在播放”中的 Genius 控件，可根据选中歌曲创建推荐播放列表。DeepSeek 只从请求开始时固定下来的本地可用歌曲元数据中选择。预览会保留推荐顺序，**刷新**、**播放**和**保存**均沿用该顺序，并使用现有的播放列表存储机制。这是基于本地曲库的推荐功能；其验证与取消规则见 [DeepSeek Genius 与翻译说明](docs/DEEPSEEK_GENIUS_TRANSLATION_PLAN.md)。

在 iPod 屏幕中打开 **设置 → 歌词**，通过**翻译目标语言**选择 English / 简体中文 / 日本語；**翻译当前歌曲 → 翻译歌词**会翻译正在播放的歌曲。原生“播放”菜单提供相同命令。翻译目标语言独立于界面语言保存。原歌词、译文和可选罗马音按原始行及时间戳保持对应。有效的缓存译文可离线使用；**重新生成翻译**会请求新结果。**显示翻译**与单独按 **T** 控制同一个持久化显示偏好。按 T 开启时，若缺少译文会开始生成，必要时先联网查找原歌词；设置里的“显示翻译”开关只改变显示状态。原歌词始终可见；开启译文后，译文显示在原文下方，同时隐藏罗马音。关闭后恢复原有的 **R** / 罗马音偏好。稍后完成的翻译不会覆盖已经通过 T 关闭的显示状态。**取消翻译**和**移除翻译**用于管理请求和缓存。

电脑端在无歌词的“正在播放”页面单独按 **F**，即可联网查找歌词，并在歌词区域持续显示查找状态；F 只查找原歌词，不触发翻译，也不会替换已有同步歌词或手动导入的歌词。列表里的 **F + 字母**仍用于跳转，自定义 F 快捷键优先。“在线查找歌词”也可在快捷键设置中单独绑定。电脑端 **设置 → 翻译当前歌曲**可直接进入翻译操作，原有的 **设置 → 歌词 → 翻译当前歌曲**入口仍然保留。

如果此前下载的只有纯文本歌词，再按 **F** 可重新查找现成的同步版本。配置了 DeepSeek 时，纯文本结果会继续触发同步歌词来源搜索，并要求核对录音室／现场版、现场地点或年份、专辑和时长；不会让模型编造时间戳。下载结果仍须通过本地版本和时长检查，找不到就保留原歌词。已有同步歌词、手动导入和移除记录受到保护。标签未标明的现场版本，无法仅凭文本保证识别正确。

歌曲没有歌词时，**翻译歌词**会先在 [LRCLIB](https://lrclib.net/docs) 查找匹配的录音版本；只有在需要且已配置时，才会使用 DeepSeek 作为可选的查找回退，再继续翻译。查找歌词本身不需要 DeepSeek 密钥。匹配会处理排版字符、合作艺人署名和专辑发行标记，同时检查录音版本和时长；无法明确区分版本时需要手动导入。请求按间隔发送，遵守服务端冷却时间，并短暂缓存重复的未命中结果。**设置 → 歌词 → 查找或编辑歌词**允许选择任意歌曲，无需开始播放，然后进入专属的查找页面。**在线查找歌词**只执行查找，并保留状态信息。现有歌词会被保留；下载歌词会保留真实 LRC 时间戳，只有普通文本时则保持无时间轴状态。手动导入、移除和歌曲变更优先于未完成的结果。下载内容使用现有的本地歌词关联机制，并保留来源网址，因此重启后仍可使用。不会修改音频文件。详见[歌词查找与翻译验证记录](docs/TRANSLATION_SETTINGS.md)。

网络请求只会在明确执行相关操作后开始。查找会将歌曲元数据发送给 LRCLIB，以及在必要且已配置时发送给 DeepSeek；翻译会将原歌词文本发送给 DeepSeek。DeepSeek 用量计入你的账户。取消操作会阻止后续阶段和结果应用；已发出的 HTTP 请求仍受各自的超时限制。

## 播放列表

打开 **音乐 → 播放列表 → 添加播放列表**，或 **文件 → 新建播放列表…**。“添加播放列表”位于“所有歌曲”上方，支持 J/K 导航，按 Enter 打开。可输入名称，按 Enter 离开名称输入框，再用复选框或 **J/K + Space** 选择歌曲。选中歌曲后即可进入预览；名称留空时会自动使用不重复的“新建播放列表 N”名称。进入预览后，可用“上移”“下移”或“移除”调整顺序和内容，最后选择“创建”。保存的列表会出现在“音乐 → 播放列表”中，重启后保留，播放队列遵循你指定的顺序。取消不会改变曲库或播放状态。保存操作在后台完成；失败时保留草稿以便重试。

名称必须非空、为单行且不超过 100 个字符；重名检查不区分大小写。缺失的文件路径仍会保存，当前曲库中不存在的歌曲会被跳过。已保存的播放列表支持编辑歌曲及其顺序；尚未实现删除整个已保存播放列表和 iTunes 同步。

## 歌曲评分

在“正在播放”中点击封面显示控件，再点击专辑曲目列表按钮。专辑歌曲上方的五个圆点可通过点击或拖动设为零至五星，对应 iPod nano 使用指南第 23 页的交互。向第一个圆点左侧拖动，或按 **0**，可清除评分；评分区域可见时，按 **1–5** 设置星级。自定义快捷键优先，文本输入时保持正常编辑行为。

星级上方的小标题会标明正在评分的歌曲。即使播放切换到下一首，它仍保持指向原歌曲；重新打开曲目列表才会切换到当前播放的歌曲。评分保存在本地 SQLite 中，重启和重新扫描后保留；确认的文件重命名事件会将评分转移到新路径。保存异步进行，关闭应用前会完成已排队的写入。保存失败会恢复上一次成功保存的评分，并显示提示。不会改写音频标签；iTunes 同步不在当前桌面播放器的实现范围内。

## 播放、文件监控与智能播放列表

**设置 → 播放 → 无缝播放**会在同一个音频输出中预排下一首符合条件的歌曲。循环、随机播放、跳转进度或队列变更会使尚未开始的后续歌曲失效；解码格式提供编码延迟与填充信息时，会去掉这些部分。这可用于连续专辑播放，不会添加交叉淡化。

**设置 → 播放**集中提供**音量均衡**、**音量增益**和**防止失真**。音量均衡使用 ReplayGain 标签，可明确选择“关”“按歌曲”或“按专辑”；音量增益可在 −12 到 +12 dB 之间选择。专辑增益缺失时会回退到歌曲增益，没有标签的歌曲保留原始音量。这些设置会被保存，并应用于之后加载的歌曲，包括下一首无缝衔接的歌曲。用户音量控制保持独立。

macOS 上，播放器会向系统“正在播放”发布元数据、时长、播放位置和可选封面，并接收播放 / 暂停、上一首 / 下一首及进度跳转命令。停止音乐或切换到视频时，会清除系统中的音乐元数据。实体媒体键和控制中心的行为仍需实机验证。

桌面曲库会先显示启动缓存，再在后台对导入目录执行一次增量刷新。可通过**文件 → 刷新曲库**或**设置 → 刷新曲库**发现新文件、更新元数据和清理确认失效的条目。磁盘暂不可用或扫描不完整时保留缓存歌曲；有效的当前播放和稳定队列位置不受影响。常驻文件监听已移除。导入目录会跨重启保留，旧配置会自动迁移。详见[曲库刷新说明](docs/LIBRARY_REFRESH.md)。

**音乐 → 播放列表**提供“最近添加”“播放次数最多”“最近播放”和“从未播放”。这些动态视图基于当前可用的曲库路径计算，不影响用户播放列表或 Genius。统计保存在 SQLite 中，播放历史最多保留最近 1,000 次有效播放。一次播放会在累计有效收听达到 `max(3 秒, min(30 秒, 歌曲时长的一半))` 后计数一次；时长未知时需要 30 秒。短于三秒的歌曲仅在自然播放结束、且已实际收听至少一半时长时计数。暂停、进度停滞和拖动进度不会增加收听时长；重新开始播放会建立新的收听会话。

## 配置

设置首页包含“外观”“播放”“歌词”“语言”“键盘快捷键”和“AI 服务”。每个选项都有简短说明，开关直接显示状态，选择页面标出当前保存值。外观页提供明确的窗口样式和窗口大小选项；歌词页将显示偏好与当前歌曲操作分开。

首次启动会创建 `shortcuts.json`（版本 6）；`settings.json` 保存显示偏好和界面语言。**设置 → 语言**支持 English（默认）、简体中文和日本語。**设置 → 外观 → 字体**支持 Classic、Maple Mono 和 JetBrains Mono；字体已附带授权打包，选择会被保存，详见[字体说明](docs/FONTS.md)。音乐元数据和歌词保留原始文本。macOS 默认配置目录为 `~/Library/Application Support/Nano.Nano-Music-Player`；Windows 和 Linux 使用各自平台的应用配置目录。可通过 `--config-dir` 指定其他位置。

启动时会先显示缓存歌曲和已保存的手动歌词，再在后台刷新源文件。某个文件打开缓慢或阻塞时，不会隐藏已有曲库。后台更新会保留更新较新的导入结果、歌词编辑和当前播放队列。

视频支持内嵌字幕及匹配的 `.ass` / `.ssa` 外部字幕。**文件 → 字幕…**可选择自动、关闭或具体字幕轨，也可导入、替换或移除字幕关联。每个视频的选择会被保存，外部字幕可放在其他文件夹。ASS 样式和时间轴由 libmpv/libass 渲染，详见[字幕实现与验证](docs/SUBTITLES_IMPLEMENTATION_PLAN.md)。

播放恢复版本暂停了自动曲库监控，即使旧配置曾将其开启也不会恢复。手动导入和启动时的源文件刷新仍可使用，保存的曲库根目录和歌词都会保留。此举用于避免已复现的 macOS 文件描述符耗尽问题，详见[播放恢复验证记录](docs/PLAYBACK_RECOVERY.md)。

**设置 → 键盘快捷键**支持在应用内编辑按键。用 J/K 选择操作，按 L/Enter 打开，选择**替换按键**或**添加按键**，再按下组合键。**移除按键**会禁用该操作的快捷键，**默认按键**恢复该操作的默认绑定，**恢复所有默认设置**则重置整个键位表。修改会先检查冲突，再原子保存并立即生效；Escape 取消录制或关闭编辑器。也可在应用关闭时编辑 JSON，再重启加载，示例见 [`examples/`](examples/)。每条绑定由操作、按键及精确的修饰键组成。`primary` 在 macOS 上为 Command，其他平台为 Control；`secondary` 在 macOS 上为 Control，其他平台为 Super。删除绑定即可禁用，也可为同一操作添加别名。重复或有歧义的绑定会被拒绝，显示提示后使用默认键位。

未修改过的版本 1–3 默认键位会升级到当前导航方式和 F 前缀快捷键；自定义键位保持不变。“跳转到字母”可在设置中指定按键。主页中，H/L 在图标和页面之间横向移动，J/K 纵向移动，Enter 打开选中项；列表中，H/L 返回 / 打开，J/K 每次移动一行。在“正在播放”中，方向键还可用于跳转进度和调整音量。

`zoom` 的范围为 0.75–3.0。启动时，保存的 `window_width` 优先于 `zoom`；只有高度时使用 `window_height`。移除这两个尺寸字段后，窗口会根据 `zoom` 设置大小。屏幕模式保持 240:432，设备模式遵循完整机身的 39.6:76.5 比例。LCD 在所有缩放比例下使用同一逻辑坐标系，拖动调整窗口大小后会保存最终尺寸。

## 项目结构与验证

- `src/input/`：平台按键转换、可配置绑定，以及统一的上下文和长按重复分发。
- `src/app/`：导航栈、统一状态更新、控制器和设置。
- `src/audio/`：队列 / 循环状态，以及管理音频输出、解码器和播放队列的后台线程。
- `src/library/`：后台扫描、Lofty 元数据、SQLite 缓存和歌词。
- `ui/`：声明式 Slint 页面；根组件统一接收 `capture-key-pressed` 回调。

```sh
cargo fmt --all -- --check
cargo test --all-targets
cargo clippy --all-targets -- -D warnings
```

测试包含按键分发和状态回归、小型原创 MP3/M4A/FLAC/WAV 音频样本、内嵌歌词，以及无界面的 Slint 按键 / 指针事件和截图渲染。GUI 测试截图保存在系统临时目录。各平台的实际音频输出和手势仍需在对应操作系统上进行原生测试。

设置支持自定义快捷键、显示模式、缩放、单曲歌词和语言。主页中其余非音乐图标目前打开占位页面；电台、时钟、健身和照片尚未实现。“播放列表”包含“所有歌曲”和用户保存的播放列表。视频功能支持导入和播放本地文件、保持比例显示画面、播放 / 进度 / 音量控制，以及整个设备的横屏旋转。列表会在后台通过 FFmpeg 为可见行加载缓存帧缩略图；缩略图缺失或损坏时保留视频占位图。播放需要兼容的 libmpv，导入需要 ffprobe，详见[视频实现说明](docs/VIDEO_IMPLEMENTATION.md)中的安装方法、已验证格式和平台限制。播放器布局参考了所提供的第七代 nano 照片和 Apollomaniacs 音乐使用指南；来源、素材出处和授权见[资源说明](docs/RESOURCES.md)。

艺人、专辑和全局歌曲列表按名称排序，不区分大小写，并使用确定性的规则处理相同名称。单张专辑内按曲目编号排序。专辑和艺人列表会显示代表性封面缩略图。

稳定的应用 Bundle ID 及 AeroSpace 定向浮动规则见 [macOS 集成说明](docs/MACOS_INTEGRATION.md)。应用不会修改窗口管理器配置。[后续媒体功能](docs/FUTURE_MEDIA.md)保留了最初的视频可行性研究和未来播客架构；本地视频播放目前已实现。实施阶段和验证记录见[实现计划](docs/IMPLEMENTATION_PLAN.md)。

GitHub Actions 会原生构建 macOS Apple Silicon、Windows x86-64 和 Linux x86-64 安装包。macOS 另有本地运行验证；Windows/Linux 的实际音频输出、桌面集成和界面行为仍需手动测试。

可通过已保存播放列表中的**编辑**工具栏，或 **文件 → 编辑播放列表…**修改列表。**添加**会打开名称 / 歌曲选择器；红色减号后的**删除**会从草稿中移除一首歌曲。拖动右侧三条横线的排序把手，或使用**上移 / 下移**调整顺序；拖到列表边缘时会自动滚动。**完成**保存现有播放列表，**取消**放弃修改。编辑、随机播放和歌曲列表共用 J/K 选择逻辑，Enter/L 打开当前选中项。缺失歌曲仍会保留在存储中，但不会参与播放。Home 会保留草稿，再次选择“新建播放列表”可继续编辑。编辑过程不会改变当前播放队列。

歌曲列表、专辑集合列表和单张专辑 / 播放列表 / 流派列表顶部的**随机播放**会以当前列表为范围开始随机播放；搜索页只随机播放搜索结果。该入口支持 J/K 和 Enter/L；F 加字母跳转会跳过这一控件，只匹配歌曲元数据。关闭随机播放后会恢复列表原本的顺序。

在曲库列表中，向右滑动或横向滚动触控板可返回上一级。纵向手势用于滚动列表；轻微移动、斜向手势、对话框、文本输入及页面过渡期间的输入均有对应的手势保护。

主页在横向触控板输入及 H/L 切换页面时，使用持续保留的图标树和 180 毫秒的缓出滑动动画。到达页面边界后，持续的滚动惯性不会重置选中项，也不会继续提交导航操作。关闭 **设置 → 外观 → 页面动画**后会立即切换到目标页面；在图标上滑动只会导航，不会误启动图标。
